# Pi
## Extensions
* [`plan-mode`](../users/shared/pi/extensions/plan-mode.ts) starts read-only, disables `edit` and `write`, and persists its state. Toggle it with `/plan` or `Tab`.
* [`response-time`](../users/shared/pi/extensions/response-time.ts) shows the elapsed response duration in the status area.
* [`web-fetch`](../users/shared/pi/extensions/web-fetch.ts) adds `web_fetch` for retrieving URLs as text.

## Hotkeys
* `Tab` Toggle plan mode
* `Ctrl + P` switch model
* `Shift + Tab` switch thinking level
